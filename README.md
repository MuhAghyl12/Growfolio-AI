
# 🚀 Growfolio-AI
**Platform Portofolio Mahasiswa Berbasis AI**

Growfolio-AI adalah platform yang membantu mahasiswa membangun, mengelola, dan mengembangkan portofolio diri secara otomatis dengan bantuan kecerdasan buatan. Sistem ini memberikan rekomendasi pengembangan keterampilan, proyek, dan peluang yang sesuai dengan minat dan jurusan pengguna.

---

## ✨ Fitur Utama
- 🤖 **Analisis Profil Berbasis AI**: Mengevaluasi keterampilan, pengalaman, dan pencapaian mahasiswa
- 📈 **Rekomendasi Pengembangan**: Saran kursus, proyek, atau sertifikasi yang relevan
- 📂 **Pengelolaan Portofolio Digital**: Menyimpan dan menampilkan proyek, tugas, dan prestasi dalam satu tempat
- 🎯 **Pencocokan Peluang**: Menghubungkan mahasiswa dengan lowongan magang atau lomba yang sesuai
- 📱 **Tampilan Responsif**: Dapat diakses dengan nyaman melalui HP maupun komputer

---

## 🛠️ Teknologi yang Digunakan
- **Frontend**: HTML, CSS, JavaScript / React
- **Backend**: Python / Node.js
- **AI/ML**: TensorFlow / Scikit-learn untuk sistem rekomendasi
- **Database**: MySQL / MongoDB
